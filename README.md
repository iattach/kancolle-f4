⚠️ 使用 EXE 前的最后注意事项
当你拿到这个 .exe 并在自己的电脑上运行时：

杀毒软件拦截： 由于它是用 PyInstaller 临时打包的单文件，又含有网络拦截功能，Windows Defender 或 360 极大概率会报错。你需要在杀毒软件中手动将其添加为信任/白名单。

首次运行必须安装证书：

双击运行 kancolle_proxy.exe，让黑框保持开启。

把 poi 的代理设置为 127.0.0.1:8080。

非常关键： 此时游戏会白屏。你需要打开电脑自带的浏览器（如 Edge），在网址栏输入 [http://mitm.it](http://mitm.it)。

点击 Windows 图标下载证书，双击运行，务必将其安装到“受信任的根证书颁发机构”。

重启 poi 浏览器，游戏就能正常加载了，防断线偷油功能也已完全生效。
